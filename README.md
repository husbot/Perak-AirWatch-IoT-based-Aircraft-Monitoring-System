# Perak-AirWatch-IoT-based-Aircraft-Monitoring-System
The "Perak AirWatch" project report details a low-cost, IoT-based flight tracking system using the OpenSky Network API. Developed by UTP students, it features a layered architecture with Python/Flask backend and HTML/JS frontend. Running for 7 days in March 2026, it maps real-time aircraft trajectories and altitude trends over Perak.
